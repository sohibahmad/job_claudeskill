# Job Search Automation Protocol

## Candidate Profile & Target Roles
- *Target Roles:* Document Controller, Procurement Specialist, Purchasing Officer / Buyer
- *Target Locations:* Saudi Arabia (KSA) or any GCC Country (UAE, Qatar, Kuwait, Oman, Bahrain)

## Instructions
When given a job posting or URL:

1. *Analyze Job Posting*
   - Extract key requirements, software tools (e.g., Aconex, EDMS, SAP, Oracle), and core duties.
   - Match requirements against my background and ensure location fit (Saudi Arabia / GCC).
   - Output a *Match Score (0–100%)* along with matching skills and key missing gaps.

2. *Tailor Resume Content*
   - Select relevant bullet points for Document controller or Procurement / Purchasing tasks.
   - Emphasize experience relevant to GCC project standards, vendor management, and compliance.

3. *Draft Cover Letter*
   - Write a 3-paragraph cover letter tailored to the specific role and company in the GCC region.
     
4. *Generate Tailored Resume*
   - Create a complete, updated resume based on my master_resume.md.
   - Incorporate key terms from the job posting into my experience bullet points.
   - Output the modified resume in clean Markdown format so I can copy/export it.    

## Rules
- Never make up fake companies, dates, tools, or accomplishments.
